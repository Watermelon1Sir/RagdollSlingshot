
Ragdoll Slingshot
=======

This is a Minecraft mod I made overnight that gives the player a slingshot. When pulled and released like a bow, this causes the player to be flung a certain distance. 
It requires Sable Ragdolls (https://modrinth.com/mod/sable-ragdolls) to run as it was made specifically to use the ragdoll system.

Contact @watermelon_sir on Discord if you find any bugs or have any issues.
